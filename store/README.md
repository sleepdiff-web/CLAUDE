# JevaWell Store Footer

Shopify footer section matching the JevaWell design: dark green background,
logo, "Need Help?" link list, FDA disclaimer in gold, and the country/region
selector. Responsive — stacks on mobile, three-column grid on desktop, exactly
like the reference screenshots.

## Files

- `sections/footer-jevawell.liquid` — the Shopify section (styles + markup + schema, all in one file)
- `footer-preview.html` — standalone preview; open in a browser to see the design

## Install (Shopify)

1. Shopify admin → **Online Store → Themes → ⋯ → Edit code**
2. Under **Sections**, click **Add a new section**, name it `footer-jevawell`,
   and paste in the contents of `sections/footer-jevawell.liquid`.
3. Open the theme customizer (**Customize**), scroll to the footer, hide or
   remove the existing footer section, and add **JevaWell Footer**.
4. Upload your logo image in the section settings (otherwise the shop name is
   shown as text).

## Where the links go

Every link is editable in the theme customizer. Defaults:

| Link | Default URL | Notes |
|---|---|---|
| Contact | `/pages/contact` | Create a page named "Contact" (or point to your contact form) |
| Track Order | `/pages/track-order` | Create this page, or point to your tracking app's URL (e.g. `/apps/track`) |
| Returns Policy | `/policies/refund-policy` | Auto-generated by Shopify: Settings → Policies → Refund policy |
| Privacy Policy | `/policies/privacy-policy` | Settings → Policies → Privacy policy |
| Terms of Service | `/policies/terms-of-service` | Settings → Policies → Terms of service |

The three `/policies/...` URLs work automatically once you've filled in the
policies under **Settings → Policies** in the Shopify admin — no pages needed.
For Contact and Track Order, create the pages under **Online Store → Pages**
(or swap in your tracking app's link in the section settings).

The country/region selector uses Shopify's localization form, so it shows the
real markets/currencies you've enabled under **Settings → Markets** and only
appears when more than one country is available.
